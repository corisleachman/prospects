## Design Context

### Users

The product is used by Coris and a junior researcher working through UK agency prospects. They need to verify people, capture credible evidence, review suggested reasons to speak and keep outreach decisions human-controlled. The interface should support quick, careful work without asking either user to understand the underlying data model.

### Brand Personality

Focused, practical and assured. The product should feel like the current Prospects dashboard: direct, compact and calm, with plain language and clear consequences for every action.

### Aesthetic Direction

Preserve the current interface exactly for now. Continue its warm cream canvas, deep navy structure, coral action colour, DM Sans and DM Mono typography, compact controls, pill buttons and restrained motion. New work should look native to the existing static dashboard, not like a separate product or a visual redesign.

Avoid generic SaaS cards, gradients, glass effects, decorative metrics and new visual systems. Broader UI changes can be considered later as a separate piece of work.

### Design Principles

- Extend existing screens and patterns before adding new navigation or layout ideas.
- Keep research actions fast, explicit and easy to verify.
- Show source, date and company or person context wherever evidence is reviewed.
- Use the existing hierarchy, colour tokens, typography and interaction behaviour.
- Keep outreach and final judgement with a person. Never imply that a message was sent automatically.
